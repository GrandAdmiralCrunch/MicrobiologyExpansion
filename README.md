# MicrobiologyExpansion
A mod for KSP that adds microbial life to Kerbin and the world's beyond


### Features

- **Mystery Goo Bioscan** - Adds bioscan capability to the stock Mystery Goo container
- **Microbe Sample Return** - Scientists on EVA can collect Microbe samples that can be returned to Kerbin for science
- 
- ## Microbe Discovery System
- Over 50 unique microbes spread across the Kerbol system, each with a name, category, home planet, biome restrictions, flavor text, spawn chance, and science value.
- Each bioscan randomly selects one eligible microbe from the current biome - discovering a new one awards science

- ## Microbiology Codex UI
- An in-game codex window that displays all microbes with their icon, category, home planet, biome(s), description, and science value.

## Installation
 
1. Ensure you have **Module Manager** installed (required dependency).
2. Download the latest release `.zip`.
3. Extract the contents into your KSP `GameData/` folder.
4. The final path should look like: `GameData/MicrobiologyExpansion/`


## Compatibility
 
- Should be compatible with most Mods, though microbes will only spawn on planets defined in `Microbes.cfg`.
